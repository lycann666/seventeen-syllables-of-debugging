A deterministic Python program for make.fun's "Seventeen Syllables of Debugging" bounty. It writes one haiku about debugging — three lines in the 5-7-5 syllable shape, at most 200 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
python3 main.py
```
